# 不新手老师：提交材料与复现说明草稿

## 项目与演示

项目面向小学教师，包含电脑端教学工作台和 IrisView 眼镜模拟器端。教师导入课件、讨论并确认课次卡；课堂界面显示时间和活动倒计时；课后参考课堂记录对话并保存复盘文档。作品说明见同目录的 PDF；演示课件位于 `agent/演示课件/认识三角形.pdf`。

演示使用 IrisView 模拟器；实体眼镜与其麦克风链路未验证。本地语音采用 faster-whisper `tiny` 多语言模型；语音结果取决于环境和设备。模型对话须另行配置兼容接口，课堂转写及课件文字可能按配置发送给模型服务。所有课件与课堂记录均须取得使用授权；复盘需教师核对。

## 文件与依赖

- `agent/server`：本地 Node 服务、模型对话、知识库、课程存储、事件桥及课堂分析。
- `agent/web`：电脑端网页。
- `teacher-demo/dev-work/project`：眼镜端源码、清单及测试；官方 IrisView 开发工具和模拟器需由赛事资源另行安装。
- `agent/build/nonteacher-loop.fuiapp`：当前本地眼镜应用包；已由官方 SDK 测试、构建及验证，完整包 SHA-256 及边界见验收记录。冻结前仍须在实际模拟器复核。
- `agent/tools`：文档解析、语音服务、构建及启动脚本。
- 环境：Windows、WSL Ubuntu、官方 IrisView 开发工具及模拟器、Node.js（眼镜工程要求 24.13.0；电脑端 package 要求 >=22.19）、Windows Python 与 `agent/tools/document-requirements.txt` 中固定依赖；ASR 另需 WSL 中安装 `faster-whisper`、`numpy`、模型文件。

## 当前本机启动

在原机器双击 `agent/启动不新手老师.vbs`。打开网页后配置模型，检查模拟器及本地语音状态，导入课件并创建课程。依次完成备课、导入课次卡、课堂、下课及复盘。课堂语音需按官方 Client 提示授权；模拟器使用的麦克风不等同于实体眼镜麦克风。

电脑端和眼镜端源码有更新后，需先结束已有电脑端服务和模拟器，再重新启动，使新代码及 `agent/build/nonteacher-loop.fuiapp` 生效。启动器在探测到已有电脑端服务时会复用该服务，不会自动重新加载它。

**迁移限制：此版本尚未完成其他电脑的开箱复现。** `agent/tools/desktop-launch.ps1` 的 WSL 路径、`teacher-demo/dev-work/project/src/bridge.js` 的默认桥目录包含开发机路径；部分脚本还假设 `~/IrisView/LLVISION/IrisView-Developer-Kit-v1.0.0` 及特定本地语音虚拟环境已存在。更换路径后必须重新构建眼镜应用，并验证两端桥目录一致；不能把本机快捷方式直接当作跨电脑安装包。

## 模型、账号与依赖声明

对话模型通过网页配置符合现有接口的服务地址、模型名及用户自行申请的密钥；具体服务账号与额度由使用者依各提供方要求申请。文档解析支持 Markdown、文本、可提取文字的 PDF、PPTX、DOCX；图片及识别限制见 `agent/LOOP-RUN.md`。

提交时不得包含 `agent/data/provider.json`、`.env.local`、密钥文件、真实课堂数据、日志、浏览器配置或模型缓存。不要直接压缩整个工作目录；应先审核拟提交文件内容与许可。

## 素材和 AI 使用说明草稿

- 赛事模拟器与开发工具：使用赛事方提供的 IrisView 资源，具体版本及分发许可需按赛事方最终要求填写和核实。
- 演示数据与素材：使用项目演示课件《认识三角形》及项目图标；课堂演示为模拟场景，不当作真实教学效果数据。
- AI 使用：项目开发过程中使用 AI 辅助代码、设计、文字整理与测试准备；模型参与备课对话、课堂提示和复盘。相关输出由参赛者核对，模型与接口的实际名称、使用范围及费用依最终配置补充。
- 团队与贡献：本项目为**单人参赛**。参赛者提出教学场景及产品需求，参与功能测试，制作并审核演示视频，负责项目成果和提交内容；代码、设计、文档及测试准备过程中使用了 AI 辅助。

5. 扫描提交包中的凭据和个人数据，核对赛事平台最新提交要求后上传。
