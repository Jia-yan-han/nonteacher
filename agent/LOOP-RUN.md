# 桌面启动与课堂测试

双击桌面上的「不新手老师」快捷方式；也可以双击本文件夹中的 `启动不新手老师.vbs`。启动器会打开网页，同时启动本地后台、语音识别和 IrisView 模拟器。组件的输出保存在 `agent/logs/`。

1. 网页左下角查看「模拟器已连接」「本地语音识别已就绪」，并检查模型接入状态。启动模型和模拟器可能需要一些时间。
2. 在课程库选一堂课，进入备课对话，整理并导入课次卡。
3. 在课程的「课堂」中检查课次卡，点击「开始上课」。系统会下发课卡、启动旁听，并向模拟器发送开始课堂和麦克风启动请求。设备诊断中的手动下发用于排查问题。
4. 在 IrisView Client 按平台提示确认麦克风权限。网页会显示「等待麦克风授权」「麦克风采集中」等状态；眼镜收到同一课次卡后页面会显示确认。
5. 正常讲话，语音通过官方 Client 采集、由本机 ASR 转写，自动进入旁听。查看独立的 `LLVISION Agent Platform - Mono` 窗口和网页中的课堂记录。
6. 测试完成后，在网页点击「下课」结束课堂并停止旁听和眼镜端录音。接着可在网页中查看记录、生成复盘。

眼镜端在课堂期间显示当前环节、课堂已用时间和活动倒计时。模拟测试可通过 Client 文本入口输入“开始讨论”“给大家三分钟讨论”“再加一分钟”“结束计时”；环节名称应与课次卡一致。真实语音效果取决于麦克风与语音识别链路。

如果电脑显示上课中但眼镜停留在课前，展开课堂页面的设备准备区域，待眼镜收到当前课卡后点击「恢复眼镜课堂」。恢复会继续当前会话，不重新下发课卡或清空课堂记录。输入模拟文字后还需点击 Client 的「提交文字」。

网页上的「请求麦克风」可在需要重新请求时使用；每次请求都遵循官方 Client 和操作系统的授权流程。官方 API 将单次录音限制为 60 秒，到时应用会尝试重新申请；是否需要再次确认由 Client 决定。

## 输入设备与边界

- **模拟器**调用的是电脑当前可用的麦克风。若要用真实眼镜的麦克风，需先确认眼镜及配套 Client 将它接入为受支持的输入设备；本项目尚未在真实眼镜上验证。
- 本地 ASR 使用 `faster-whisper` 的 `tiny` 多语言模型；语音在本机识别。识别出的课堂文字会按现有模型配置发送给模型服务，用于生成提示和复盘。
- 测试中如果状态停在「等待麦克风授权」，请切换到 IrisView Client 查看授权提示；如果不可用，检查 WSLg 和电脑的麦克风权限及默认输入设备。
- 模拟器与眼镜的心跳不等同于硬件连接成功；界面里的“模拟器已连接”仅代表本机文件桥收到了应用心跳。
- 如果启动时报 4321 端口被占用，请在原先的服务终端按 Ctrl+C 后重试。启动器不会自动结束其他服务。

## 课件与资料

- 网页知识库支持 Markdown、文本、可提取文字的 PDF、PPTX 和 DOCX。PDF 图片页在 Windows 上尝试系统 OCR；识别结果可能漏字或有误，须在预览中核对。PPTX/DOCX 提取正文和表格文字，不读取图片内容。旧版 PPT/DOC 须另存为 PPTX/DOCX。
- 资料导入后看是否显示“已提取文字”，打开文件查看正文与解析提示；已存在且没有文字的资料，可在预览中点击“重新提取文字”。
- 备课对话可指定文件名；只说“课件”时默认选择最近一份可读取材料。内容过长时，模型只能看到前 12000 字和检索片段，需分段提问或精简资料。提取的文字会根据模型配置发送给模型服务。
- 文档解析需 Windows 的 Python、`pypdf` 和 `Pillow`；缺少时可执行 `python -m pip install -r agent/tools/document-requirements.txt`。图片 OCR 还需 Windows 中文 OCR 能力；本地示例课件为可直接提取文字的 PDF。
- 演示课件：`agent/演示课件/认识三角形.html`（键盘左右键翻页）和同目录的 `认识三角形.pdf`。

## 测试状态

已通过隔离数据的桌面服务启动测试、模拟官方音频 API 的自动采集流程、文本处理链路测试、一次中文合成语音 ASR 测试，以及官方 SDK 的 test / build / package / verify。

尚未验证真实麦克风权限、模拟器声音设备、真实课堂语音质量、实体眼镜音频链路或现场的完整闭环。赛题要求的跨方式纠正、8 项验收、10 次延迟记录和提交材料仍需另行完成。
